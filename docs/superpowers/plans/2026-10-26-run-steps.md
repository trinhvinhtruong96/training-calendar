# Run Steps in the Day Details Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a day with a run is opened, the day details show what was run in each planned step (with ✓ / !
against the plan), fetched once per run from intervals.icu and saved on the device; the Performance card's
"Each run" list is removed.

**Architecture:** A new pure module `site/src/steps.js` matches a run's watch laps to the workout's planned steps
and returns display rows. `site/src/api.js` gets a saved-laps store (`tc.v1.laps`), shared by the Performance
card and the day details, and a soft `loadDayLaps()` that never logs anyone out. `site/src/app.js` renders a
Steps section (or a Laps list for extra runs) inside the day details, filled asynchronously.

**Tech Stack:** Plain HTML/CSS/ES modules, no build step, no dependencies; `npm test` (node --test).

**Spec:** `docs/superpowers/specs/2026-10-26-run-steps-design.md`

## Global Constraints

- No framework, no build step, no runtime dependencies; plain ES modules.
- Read-only `GET`s to `https://intervals.icu` only; render with `h()` / `textContent` only.
- **No new unit tests** (user decision); `npm test` must pass (CI runs it before every deploy). Existing tests
  change only where this plan changes what they assert.
- **Never print, log or commit an API key.** Keys come from `%USERPROFILE%\.intervals_key` at run time.
- Matching (spec §4): ignore laps `< 20 m`; distance step `tol = max(100 m, 10 %)`, overshoot limit
  `max(tol, 300 m)`; timed step `tol = 15 s`, overshoot limit `30 s`; then "closer to the plan" rule.
- Verdicts (spec §5): easy steps `HR ≤ easyLimit + 3`; reps / short race pace `± 2 s`; threshold/settle/tempo
  `≥ fast − 5 s` and `HR ≤ lt + 2`, slower than `slow + 5 s` → note only; steady / long race pace `± 3 s`;
  stride, walk, rest, race, test → no verdict.
- New file under `site/` → add to `FILES` in `site/sw.js`.

## Review Focus

1. **Laps that don't fit the plan** (manual lap press mid-step, run stopped early): rows must stop at the last
   step that fits; the rest shows as plain laps or "Not done" — never numbers attributed to the wrong step.
   → Task 1, Step 2.
2. **Opening an unsaved day offline**: "Couldn't load the laps" with Try again, which works once online.
   → Task 3, Step 4.
3. **Switching days while laps load**: a late result must not be drawn into another day's details.
   → Task 3, Step 4.
4. **Forget / Log out / new key during a refresh**: no laps are saved for the forgotten credential.
   → Task 2, Step 6.
5. **Run with one lap, or not analysed yet** (empty reply): "No laps from your watch" / "Laps aren't ready
   yet"; empty replies are not saved. → Task 1, Step 2 and Task 2, Step 6.

### Task 1: Match laps to planned steps (`steps.js`)

**Files:**
- Create: `site/src/steps.js`

**Interfaces:**
- Consumes: `formatClock`, `formatKm`, `formatPace` (`dates.js`); `flattenSteps`, `formatStepAmount`,
  `paceRange`, `stepName` (`workout.js`). Workout shape = a model workout: `{ type, steps: [{text, distance,
  duration, pace: {start,end,units}, reps, steps}] }`. Laps = `[{distance, movingTime, avgHr}]`.
  Limits = `{ lt, easyLimit }` (numbers or null).
- Produces (used by Task 3):
  - `matchSteps(workout, laps, limits) →`
    - `{ kind: "single" }` — the run has 0 or 1 lap
    - `{ kind: "laps", lines: string[] }` — the workout has no steps
    - `{ kind: "steps", items: Item[], after: string|null, notDone: string[], unmatched: string[] }`
    - `Item` = `{ kind: "step", name, planned, done, status: "ok"|"check"|null, reason }` or
      `{ kind: "repeat", name, planned, done, status, reason, rows: Row[] }`; `Row` = `{ name, planned, done,
      status, reason }`
  - `lapLines(laps, first = 1) → string[]` ("Lap 1: 1 km · 5:44 · 5:44 /km · HR 139"; `formatKm` drops trailing zeros)

```js
// Matches a run's watch laps to its planned steps, for the day details.
// Pure. Spec: docs/superpowers/specs/2026-10-26-run-steps-design.md §4–§5
import { formatClock, formatKm, formatPace } from "./dates.js";
import { flattenSteps, formatStepAmount, paceRange, stepName } from "./workout.js";

const MIN_LAP_M = 20;
const SHORT_SESSIONS = new Set(["intervals", "racepace"]);
const NONE = Object.freeze({ status: null, reason: "" });

const paceOf = (metres, seconds) => (metres > 0 && seconds > 0 ? seconds / (metres / 1000) : null);
const cueOf = step => String(step?.text ?? "").trim().toLowerCase();
const isEasyCue = cue => /^(warm-?up|easy|cool-?down)\b/.test(cue);

function rangeOf(step) {
  const p = step?.pace;
  if (!p || p.start == null || p.end == null || (p.units && p.units !== "secs/km")) return null;
  return [Math.min(p.start, p.end), Math.max(p.start, p.end)];
}

// A step whose pace is the point of the repeat (rep, block, race pace), as opposed to rests, walks, strides.
const isWork = step => Boolean(rangeOf(step)) && !isEasyCue(cueOf(step));

function paceSpan(paces) {
  const lo = formatPace(Math.min(...paces));
  const hi = formatPace(Math.max(...paces));
  return lo === hi ? lo : `${lo}–${hi}`;
}

// Distance, time, pace and time-weighted HR of some laps.
function totals(laps) {
  const distance = laps.reduce((s, l) => s + (l.distance || 0), 0);
  const time = laps.reduce((s, l) => s + (l.movingTime || 0), 0);
  const withHr = laps.filter(l => l.avgHr > 0 && l.movingTime > 0);
  const hrTime = withHr.reduce((s, l) => s + l.movingTime, 0);
  const hrs = withHr.map(l => Math.round(l.avgHr));
  return {
    distance,
    time,
    pace: paceOf(distance, time),
    hr: hrTime ? Math.round(withHr.reduce((s, l) => s + l.avgHr * l.movingTime, 0) / hrTime) : null,
    hrLo: hrs.length ? Math.min(...hrs) : null,
    hrHi: hrs.length ? Math.max(...hrs) : null,
    laps: laps.length,
  };
}

function hrText(t) {
  if (t.hr == null) return "";
  return t.laps >= 2 && t.hrLo !== t.hrHi ? ` · HR ${t.hrLo}–${t.hrHi}` : ` · HR ${t.hr}`;
}

function doneText(t, timed) {
  if (timed) return `${formatClock(t.time)} · ${Math.round(t.distance)} m${hrText(t)}`;
  const pace = t.pace ? ` · ${formatPace(t.pace)} /km` : "";
  return `${formatKm(t.distance, 2)} km · ${formatClock(t.time)}${pace}${hrText(t)}`;
}

function plannedText(step) {
  const pace = paceRange(step.pace);
  return [formatStepAmount(step), pace ? `@${pace}` : ""].filter(Boolean).join(" ");
}

export function lapLines(laps, first = 1) {
  return (laps ?? []).filter(l => (l.distance || 0) >= MIN_LAP_M)
    .map((l, i) => `Lap ${first + i}: ${doneText(totals([l]), false)}`);
}

function within(t, range, slack) {
  if (!range || t.pace == null) return NONE;
  if (t.pace < range[0] - slack) return { status: "check", reason: "too fast" };
  if (t.pace > range[1] + slack) return { status: "check", reason: "too slow" };
  return { status: "ok", reason: "" };
}

// Spec §5. Checks needing HR or a limit are skipped when either is missing.
export function stepVerdict(step, t, limits, workoutType) {
  const cue = cueOf(step);
  const range = rangeOf(step);
  if (isEasyCue(cue)) {
    if (t.hr == null || !limits?.easyLimit) return NONE;
    return t.hr <= limits.easyLimit + 3 ? { status: "ok", reason: "" } : { status: "check", reason: `HR above ${limits.easyLimit}` };
  }
  if (/^rep\b/.test(cue) || (/^race pace\b/.test(cue) && SHORT_SESSIONS.has(workoutType))) return within(t, range, 2);
  if (/^(threshold|settle|tempo)\b/.test(cue)) {
    const reasons = [];
    if (range && t.pace != null && t.pace < range[0] - 5) reasons.push("too fast");
    if (limits?.lt && t.hr != null && t.hr > limits.lt + 2) reasons.push(`HR above ${limits.lt}`);
    if (reasons.length) return { status: "check", reason: reasons.join(", ") };
    if (range && t.pace != null && t.pace > range[1] + 5) return { status: null, reason: "slower than planned" };
    const checked = (range && t.pace != null) || (limits?.lt && t.hr != null);
    return checked ? { status: "ok", reason: "" } : NONE;
  }
  if (/^(steady|race pace)\b/.test(cue)) return within(t, range, 3);
  return NONE;
}

// Planned steps in order; a repeat becomes its steps × reps, remembering the group and rep number.
function expand(steps) {
  const out = [];
  (steps ?? []).forEach((s, group) => {
    if (s.reps && Array.isArray(s.steps)) {
      for (let rep = 1; rep <= s.reps; rep++) for (const inner of flattenSteps(s.steps)) out.push({ step: inner, group, rep });
    } else {
      out.push({ step: s, group: null, rep: null });
    }
  });
  return out;
}

// Laps for one step from position `from`, or null when they don't fit (spec §4.3).
function take(laps, from, step) {
  const timed = !(step.distance > 0);
  const target = timed ? step.duration || 0 : step.distance;
  if (!target) return null;
  const tol = timed ? 15 : Math.max(100, 0.1 * target);
  const over = timed ? 30 : Math.max(tol, 300);
  const size = l => (timed ? l.movingTime : l.distance) || 0;
  let i = from;
  let sum = 0;
  while (i < laps.length && sum < target - tol) sum += size(laps[i++]);
  if (sum < target - tol) return null; // laps ran out
  while (i < laps.length && Math.abs(sum + size(laps[i]) - target) < Math.abs(sum - target)) sum += size(laps[i++]);
  if (sum > target + over) return null; // one lap covers this step and more: laps don't follow the plan
  return { next: i, laps: laps.slice(from, i), timed };
}

function repeatHeader(groupStep) {
  const inner = flattenSteps(groupStep.steps ?? []);
  const work = inner.filter(isWork);
  if (work.length === 1) {
    const others = inner.filter(s => s !== work[0]).map(s => `${formatStepAmount(s)} ${stepName(s.text).toLowerCase()}`);
    const pace = paceRange(work[0].pace);
    return {
      name: `${groupStep.reps} × ${formatStepAmount(work[0])}`,
      planned: [pace ? `@${pace}` : "", ...others].filter(Boolean).join(" · "),
      label: /^rep\b/.test(cueOf(work[0])) ? "reps" : "blocks",
    };
  }
  return { name: `${groupStep.reps} × (${inner.map(formatStepAmount).join(" + ")})`, planned: "", label: "blocks" };
}

function repeatSummary(g, reps) {
  const work = g.rows.filter(r => r.work);
  if (!work.length) {
    const done = new Set(g.rows.map(r => r.rep)).size;
    return { done: `${done} of ${reps} done`, status: null, reason: "" };
  }
  const count = word => work.filter(r => r.reason.includes(word)).length;
  const parts = [];
  if (count("too fast")) parts.push(`${count("too fast")} too fast`);
  if (count("too slow")) parts.push(`${count("too slow")} too slow`);
  if (count("HR above")) parts.push(`${count("HR above")} with HR too high`);
  const anyCheck = work.some(r => r.status === "check");
  const anyOk = work.some(r => r.status === "ok");
  return {
    done: `${g.label} ${paceSpan(work.filter(r => r.pace != null).map(r => r.pace))}`,
    status: anyCheck ? "check" : anyOk ? "ok" : null,
    reason: parts.length ? parts.join(", ") : anyOk ? "all on target" : "",
  };
}

function group(rows, steps) {
  const items = [];
  for (const r of rows) {
    const row = { name: r.name, planned: r.planned, done: r.done, status: r.status, reason: r.reason };
    if (r.group == null) {
      items.push({ kind: "step", ...row });
      continue;
    }
    let g = items[items.length - 1];
    if (!g || g.kind !== "repeat" || g.group !== r.group) {
      g = { kind: "repeat", group: r.group, ...repeatHeader(steps[r.group]), rows: [] };
      items.push(g);
    }
    g.rows.push({ ...row, name: isWork(r.step) ? `${r.name} ${r.rep}` : r.name, work: isWork(r.step), rep: r.rep, pace: r.pace });
  }
  return items.map(it => {
    if (it.kind !== "repeat") return it;
    const summary = repeatSummary(it, steps[it.group].reps);
    return {
      kind: "repeat",
      name: it.name,
      planned: it.planned,
      ...summary,
      rows: it.rows.map(({ name, planned, done, status, reason }) => ({ name, planned, done, status, reason })),
    };
  });
}

function notDoneNames(rest, steps) {
  const names = [];
  let lastGroup = null;
  for (const p of rest) {
    if (p.group == null) {
      names.push(stepName(p.step.text));
      lastGroup = null;
    } else if (p.group !== lastGroup) {
      names.push(`${repeatHeader(steps[p.group]).name} (from rep ${p.rep})`);
      lastGroup = p.group;
    }
  }
  return names;
}

export function matchSteps(workout, rawLaps, limits = {}) {
  if ((rawLaps ?? []).length <= 1) return { kind: "single" };
  const laps = rawLaps.filter(l => (l.distance || 0) >= MIN_LAP_M);
  const plan = expand(workout?.steps);
  if (!plan.length) return { kind: "laps", lines: lapLines(laps) };
  const rows = [];
  let at = 0;
  let stopped = -1;
  for (let k = 0; k < plan.length; k++) {
    const m = take(laps, at, plan[k].step);
    if (!m) {
      stopped = k;
      break;
    }
    const t = totals(m.laps);
    rows.push({
      ...plan[k],
      name: stepName(plan[k].step.text),
      planned: plannedText(plan[k].step),
      done: doneText(t, m.timed),
      pace: t.pace,
      ...stepVerdict(plan[k].step, t, limits, workout?.type),
    });
    at = m.next;
  }
  const rest = laps.slice(at);
  const result = { kind: "steps", items: group(rows, workout.steps), after: null, notDone: [], unmatched: [] };
  if (stopped < 0) {
    if (rest.length) result.after = doneText(totals(rest), false);
  } else if (rest.length) {
    result.unmatched = lapLines(rest, at + 1);
  } else {
    result.notDone = notDoneNames(plan.slice(stopped), workout.steps);
  }
  return result;
}
```

```js
// Saved laps are kept only for runs the page knows about (the cached activities), never empty.
export function mergeLaps(store, add, knownIds) {
  const known = new Set((knownIds ?? []).map(String));
  const next = {};
  for (const [id, laps] of Object.entries({ ...store.getLaps(), ...add })) {
    if (known.has(id) && Array.isArray(laps) && laps.length) next[id] = laps;
  }
  store.setLaps(next);
}

// Laps of one run for the day details: saved → the Performance card's → intervals.icu. Never logs out.
export async function loadDayLaps(activityId, { store, knownIds, extra = {}, fetchImpl = defaultFetch }) {
  const id = String(activityId);
  const saved = store.getLaps()[id] ?? extra?.[id];
  if (saved?.length) return { laps: saved };
  const auth = store.getAuth();
  if (!auth) return { error: true };
  const res = await softRequest(`/activity/${encodeURIComponent(id)}/intervals`, auth, fetchImpl);
  if (res.failed) return { error: true };
  const laps = reduceLaps(res.value);
  if (!laps.length) return { notReady: true };
  if (store.getAuth()?.secret === auth.secret) mergeLaps(store, { [id]: laps }, knownIds);
  return { laps };
}
```

```js
// ---------- run steps (day details) ----------
// Filled after the laps load; a late result is dropped if another day is open by then.
function stepsSection(run, workout) {
  const box = h("div", { class: "steps-result" });
  fillSteps(box, run, workout);
  return box;
}

function fillSteps(box, run, workout) {
  const date = state.detailsDate;
  box.replaceChildren(stepsTitle(workout), h("p", { class: "muted small", text: "Loading laps…" }));
  loadDayLaps(run.id, {
    store,
    knownIds: (state.data?.activities ?? []).map(a => a.id),
    extra: state.data?.performance?.laps ?? {},
  }).then(res => {
    if (!box.isConnected || state.detailsDate !== date) return;
    box.replaceChildren(...stepsContent(res, run, workout, box));
  });
}

const stepsTitle = workout => h("h4", { class: "steps-title", text: workout ? "Steps" : "Laps" });

function stepsContent(res, run, workout, box) {
  const title = stepsTitle(workout);
  const note = text => h("p", { class: "muted small", text });
  if (res.error) {
    return [title, note("Couldn't load the laps."),
      h("button", { type: "button", class: "btn ghost small", onclick: () => fillSteps(box, run, workout) }, "Try again")];
  }
  if (res.notReady) return [title, note("Laps aren't ready yet in intervals.icu.")];
  const m = workout ? matchSteps(workout, res.laps, state.performance?.limits ?? {}) : { kind: "laps", lines: lapLines(res.laps) };
  if (m.kind === "single" || (m.kind === "laps" && !m.lines.length)) return [title, note("No laps from your watch.")];
  const lines = items => h("ul", { class: "perf-list steps-list" }, items.map(t => perfItem("none", h("span", { text: t }))));
  if (m.kind === "laps") return [title, lines(m.lines)];
  const list = h("ul", { class: "perf-list steps-list" });
  m.items.forEach((it, i) => {
    if (it.kind === "step") {
      list.append(stepRow(it));
      return;
    }
    const id = `reps-${run.id}-${i}`;
    list.append(
      stepRow(it, h("button", {
        type: "button", class: "btn ghost small", "aria-expanded": "false", "aria-controls": id,
        onclick: e => toggleReps(e.currentTarget, id),
      }, "Show reps")),
      h("li", { class: "steps-reps", id, hidden: true }, h("ul", { class: "perf-list" }, it.rows.map(r => stepRow(r)))));
  });
  if (m.after) list.append(perfItem("none", h("strong", { text: "After the workout" }), h("span", { class: "step-done", text: m.after })));
  const out = [title, list];
  if (m.notDone.length) out.push(note(`Not done: ${m.notDone.join(", ")}`));
  if (m.unmatched.length) out.push(note("Steps after this didn't match your laps:"), lines(m.unmatched));
  return out;
}

function stepRow(r, extra = "") {
  return perfItem(r.status ?? "none",
    h("strong", { text: r.name }),
    r.planned ? h("span", { class: "muted", text: ` · ${r.planned}` }) : "",
    h("span", { class: "step-done", text: [r.done, r.reason].filter(Boolean).join(" · ") }),
    extra);
}

function toggleReps(btn, id) {
  const open = btn.getAttribute("aria-expanded") !== "true";
  btn.setAttribute("aria-expanded", String(open));
  btn.textContent = open ? "Hide reps" : "Show reps";
  document.getElementById(id).hidden = !open;
}
```
